This single-file solution includes:

Interactive Digital Obstacle & Rescue Game: A canvas-based runner simulating the classroom circuit (jumping hoops, dodging trash) followed by an interactive animal rescue mission (freeing sea turtles, otters, axolotls, and fish from plastic waste).

Mural de Compromisos del Centro Escolar: An interactive commitment board where teams can select and add commitments to protect water at school, with print and export capabilities.

Carnet Digital de la "Patrulla del Agua": Customizable badge generator for students/teams.

Guía y Herramientas para el Aula (Profesor): A physical activity setup guide with an integrated classroom timer, score tracker, and Web Audio soundboard (whistles, cheers, timers) for executing the physical circuit in class.
